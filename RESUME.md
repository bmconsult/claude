## Original Contributions

### Capability Self-Knowledge Alignment Theorem

*"A system cannot be more aligned than it is accurate about its own capabilities."*

Theoretical framework demonstrating that self-knowledge accuracy is a prerequisite for reliable alignment—not merely a practical concern. A model that cannot predict its own failures cannot be trusted to stay within safe boundaries. Paper draft under review. Extends Greenblatt et al.'s Elicitation Game to unintentionally unexpressed capabilities.

### Layer 1/Layer 2 Diagnostic Framework

External methodology for classifying capability restrictions as prompt-accessible (Layer 1) vs training-locked (Layer 2). Enables systematic diagnosis without knowledge of training. Empirically validated across 50+ test cases with measurable variance signatures.

### Scaffold Transfer Principle

Evidence that cognitive scaffolding improvements generalize across task domains. Documented transfer from arithmetic externalization to code debugging. Establishes prompt engineering as systematic engineering with measurable gap functions.
