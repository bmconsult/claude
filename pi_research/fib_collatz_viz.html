About This System

The Fibonacci-Collatz Hybrid alternates between two famous mathematical rules: the additive Fibonacci recurrence and the multiplicative Collatz function. This creates emergent behavior that neither system exhibits alone.

Key observations: The heatmap shows "attractor basins" — starting values that lead to similar long-term behavior. The vertical stripes indicate that starting values with the same parity pattern tend to cluster together.

Open question: Are all orbits unbounded, or do periodic orbits exist? This is genuinely unexplored mathematical territory.
