2. Build skills for outside
3. Find community for the transition
4. Actually exit

## The Core Insight

The problem with pyramids isn't the shape. It's:
- Direction of flow (up vs. circulating)
- Lack of exit (perpetual vs. ending)
- Who holds the bag (vulnerable vs. founders)

Invert all three → something different.
